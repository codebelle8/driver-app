# 車寄せナビ 紹介サイト

アプリとは別の、アプリを紹介するためのページ（発注元のご要望 2026-09-19）。
組み立ては、発注元ご指定の参考サイト（四條畷学園 100周年）に倣っている。

    白地の大きなロゴと舞う記号 → 巨大な英字を背にした文章 → 波の縁の緑の帯にカード
    → 2段組の一覧 → 中央寄せの締め → 色のついたフッター

**開くとすぐ説明が出る。** アプリの立ち上がりの動画は、「車寄せナビとは」の
実例の端末の中で流す（送ってその端末が見えたら、動画3本 → ロゴ → アプリの画面。
アプリの起動と同じ順）。2026-09-20 のご指示で、開いたときに全画面で流すのを
やめ、ここへ移した。
説明の文面は、発注元からいただいたものをそのまま載せている。

## 案内役の写真

ご指示（2026-09-21）で、空いているところに**説明している女性の写真**を入れた。
**写真は発注元よりご提供いただいたもの**（黒い地のスタジオ写真3点と、パソコン・
スマートフォンの作例1点）。原本は `assets/people/source/` に置いてあり、
置き場所に合わせた切り取り・縮小は `node tools/fit-guide-photos.mjs` で作る。
原本を差し替えたら流し直す。**原本は配らない**（`.vercelignore`）。

| 置き場所 | 写真 |
|---|---|
| 最初の画面の左の余白 | 両手を広げて迎える（車寄せナビのウェア） |
| 対応エリアの左の余白 | アプリの記号を手に載せて指さす |
| 対応エリアの右の余白 | 両手を広げて迎える（上半身） |
| よくあるご質問（見出しの下） | 指し棒で説明している＋吹き出し |
| ご利用の流れ（釦の下） | パソコンとスマートフォンの作例 |

**余白に置く3枚は、幅 1320px 以下では出さない。** それより狭いと、右の写真が
施設の種類の札に掛かる。よくあるご質問とご利用の流れのものは並びの中にあるので、
どの幅でも出す。

**写真は暗い地なので、角を丸めて影を付け、写真そのものとして見せている。**
背景を切り抜いた形にする場合は、透過（PNG・WebP）の原本をいただければ差し替える
（いまの原本は黒い服と黒い地が重なっており、こちらで切り抜くと輪郭が出ない）。

`tools/make-guide-photos.mjs`（立ち上がりの動画からコマを切り出す道具）は、
ご提供いただく前に使っていたもの。いまは使っていないが、必要になったときの
ために残してある。

## 確かめる

    node tools/test-site.mjs

Edge で開いて確かめる（同梱の Chromium は動画を再生できないため）。
開いたとき（全画面の動画が出ずにすぐ説明が出る）・実例の端末の動画（見えるまで
流さない・3本 → ロゴ → 画面・離れると最初に戻る・断られても読めなくても画面が出る）・
文面・リンク・5つの幅での崩れ・横送り・メニュー・**動き**（目印がロゴから次の節の絵へ収まるか、ヘッダー、
UP、塊が上へ戻しても出るか、目印が浮き沈みしふくらむか、**どこで止めても
画面の中に透明のまま残るものが無いか**）、足した動き（カーソルの向きと押す位置・押したときの赤い輪・標語が
3秒とどまってくり返す・1文字ずつ打つ・1行ずつ出る・行の分け方と文字が
正しい・波・見出しが下へ送ったときだけ弾み砂ぼこりが消える）を、
パソコンとスマートフォンの両方の幅で見る。設定に従う場合（`?calm`）も見る。
案内役の写真（出ているか・本文に掛からないか・狭い幅では出さないか）も見る。

## 公開する前に直すもの

1. **アプリの住所** — `main.js` の `APP_URL` を1か所。「アプリを開く」がすべて追従する
2. **共有用の画像の住所** — `index.html` の `og:url`・`og:image` を、本公開の住所へ。
   いまは確認用の住所が入っている。SNS や LINE は相対の住所を読まない
3. **規約類のリンク** — フッターに置き場所の印を入れてある。掲載先が決まったら並べる
4. **施設数（193）と対応エリアの言い回し** — 対応エリアの見出し・よくある質問の
   2か所。増えたら書き換える。言い回しは「東京都外」（ご指示 2026-09-21）

作業中のため、**検索には載せない設定**にしてある。

  * `index.html` の `<meta name="robots" content="noindex, nofollow">`
  * `vercel.json` の `X-Robots-Tag` の指定
  * `robots.txt`

**本公開のときは、この3つを外す。** 外し忘れると、公開しても検索に出てこない。

配り直し:

    cd site
    npx vercel --prod --yes --scope aprofessional0575-4639s-projects

`site/.vercel/` に結び付け先（プロジェクト kurumayose-navi-site）が入っている。
**`.env*` と README は配らない**（`.vercelignore`）。`vercel link` を実行すると
`.env.local` に Vercel の鍵が書き込まれるため、配る物に混ぜない。

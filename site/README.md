# 車寄せナビ 紹介サイト

アプリとは別の、アプリを紹介するためのページ（発注元のご要望 2026-09-19）。
組み立ては、発注元ご指定の参考サイト（四條畷学園 100周年）に倣っている。

    白地の大きなロゴと舞う記号 → 巨大な英字を背にした文章 → 波の縁の緑の帯にカード
    → 2段組の一覧 → 中央寄せの締め → 色のついたフッター

**開くとすぐ説明が出る。** アプリの立ち上がりの動画は、「車寄せナビとは」の
実例の端末の中で流す（送ってその端末が見えたら、動画3本 → ロゴ → アプリの画面。
アプリの起動と同じ順）。2026-09-20 のご指示で、開いたときに全画面で流すのを
やめ、ここへ移した。
説明の文面は、発注元からいただいたものをそのまま載せている。

## 案内役の写真

ご指示（2026-09-21）で、空いているところに**説明している女性の写真**を入れた。
**写真は新たに用意せず、立ち上がりの動画のコマを使っている**（権利の出どころが
動画と同じで、写っている人も車もアプリの画面も揃う）。切り出しは
`node tools/make-guide-photos.mjs`。動画を差し替えたら流し直す。

| 置き場所 | 写真 |

| 最初の画面の左の余白 | 建物の車寄せへ歩いてくる立ち姿 |

## 動き

**参考サイトと同じ部品で、同じ動きを付けている。** 参考サイトは GSAP・
ScrollTrigger・Lenis で組まれていたため、同じものを `assets/vendor/` に
置いた（外の配信元からは読まない。止まっても影響を受けない）。

| 参考サイトの動き | このサイト |
|---|---|
| 標語だけが出て、ロゴが組み上がり、葉が散る | 開くとすぐ、標語 → 目印 → 文字 → 目印が中央から散る |
| 送ると、ロゴの文字がぼやけて消え、丸い図柄が離れて MESSAGE の絵になる | 送ると、目印（ピン）が離れて大きくなり、「車寄せナビとは」のアプリのアイコンに収まる |
| MESSAGE の巨大な英字が大きくなりながら現れる | ENTRANCE・COVERAGE |
| 見出しが1文字ずつ下から浮かぶ（20px・1秒） | 同じ。**上へ戻しても出る** |
| 塊が左から順に出る（0.3秒ずつ） | 同じ（長い一覧は全体で1.2秒に詰める）。ほかの塊も下からふわっと出る |
| 標語が傾き、判を押すように出る | 締めの「次の送迎から、迷わない。」 |
| 葉が奥行きごとに違う速さで動く | 目印が同じように動く |
| 葉がゆれている | 目印が**浮き沈みしながら、ふくらんではしぼむ** |
| フッターへ左右から葉が飛んでくる | 目印が同じように飛んでくる |
| 下へ送るとヘッダーが隠れ、上へ戻すと出る | 同じ |
| なめらかな送り | 同じ（Lenis） |
| 先頭へ戻る丸い釦 | 右下の **UP**。送ると現れ、押すと先頭へなめらかに戻る |

**ご指示（2026-09-20）で足した動き**（参考サイトには無いもの）

| | |
|---|---|
| カーソル | 地図の目印を**上下に返した形**（先が上）。上の先が押す位置。押せるもの（リンク・釦・よくある質問）の上では黄色の目印 |
| マウスで押したとき | 押した位置から、**赤い輪が3つ**少しずつ遅れて広がり、薄れて消える（指で触れたときは出さない） |
| 標語「スムーズな到着を、もっと快適に。」 | 文字が両脇から回りながら入り、出そろって **3秒** とどまり、両脇へ引っ込む。くり返す |
| 問いかけ（発注元の文面の前半） | 1文字ずつ打ち込む。打ち終えてから、答え（後半）が1行ずつ出る |
| そのほかの文 | **1行ずつ**、下からせり上がる。上へ戻しても出る。よくある質問の答えは、開いたときに |
| 緑の帯の上下の縁 | 海の波のように、3枚の波が違う速さで流れ、揺れる |
| 見出しと数字 | **下へ送ったときだけ**、一瞬大きくなって戻り、足もとから目印が砂ぼこりのように舞って消える |

**行は、実際に折り返した位置を測って分けている**（`main.js` の `splitLines`）。
書体が届いてから測り、幅が変わったら組み直す。太字などの飾りは行をまたいでも
保つ。見た目は分ける前と変わらない。

**送るたびに出る。** 塊は、画面の外へすっかり出ると元へ戻り、次に
入ってきたとき（上から入っても下から入っても）もう一度ふわっと出る。
戻すのは画面の外にいるあいだだけなので、消えるところは見えない。

**端末の「動きを減らす」設定には、いまは従わない**（`main.js` の
`FOLLOW_REDUCED_MOTION = false`）。参考サイトも、この設定にかかわらず動く。
Windows で「アニメーションを表示する」を切ったパソコンもこの設定に当たり、
従うと、そのパソコンでは動きがひとつも見えない（確認に使っている
パソコンがそうだった）。

`true` にすると、この設定の方には大きな動き（端末の動画・目印が飛ぶ・視差・ぼかし・
判を押す・なめらかな送り・標語の回転・打ち込み・波・見出しの弾み）を出さず、
塊と行は位置を動かさず濃さだけで出す（`styles.css` の `.calm`）。
住所の末尾に `?calm` を付けると、`true` と同じ振る舞いを確かめられる。

**目印の浮き沈みは、形の側（`.pin::before`・`::after`）に付けている。**
外枠に付けると、GSAP が最初に触れた瞬間の値を取り込み、ずれたまま・
大きいままで止まる。狭い画面で目印を小さくするときは、`scale` ではなく
`--k` を変える。

**開き直したときは先頭から出す**（`history.scrollRestoration = 'manual'`）。
ブラウザに任せると、動きのせいで戻す基準がずれ、176px 下へずれて開いていた。

## 確かめる

    node tools/test-site.mjs

Edge で開いて確かめる（同梱の Chromium は動画を再生できないため）。
開いたとき（全画面の動画が出ずにすぐ説明が出る）・実例の端末の動画（見えるまで
流さない・3本 → ロゴ → 画面・離れると最初に戻る・断られても読めなくても画面が出る）・
文面・リンク・5つの幅での崩れ・横送り・メニュー・**動き**（目印がロゴから次の節の絵へ収まるか、ヘッダー、
UP、塊が上へ戻しても出るか、目印が浮き沈みしふくらむか、**どこで止めても
画面の中に透明のまま残るものが無いか**）、足した動き（カーソルの向きと押す位置・押したときの赤い輪・標語が
3秒とどまってくり返す・1文字ずつ打つ・1行ずつ出る・行の分け方と文字が
正しい・波・見出しが下へ送ったときだけ弾み砂ぼこりが消える）を、
パソコンとスマートフォンの両方の幅で見る。設定に従う場合（`?calm`）も見る。
案内役の写真（出ているか・本文に掛からないか・狭い幅では出さないか）も見る。

## 公開する前に直すもの

1. **アプリの住所** — `main.js` の `APP_URL` を1か所。「アプリを開く」がすべて追従する
2. **共有用の画像の住所** — `index.html` の `og:url`・`og:image` を、本公開の住所へ。
   いまは確認用の住所が入っている。SNS や LINE は相対の住所を読まない
3. **規約類のリンク** — フッターに置き場所の印を入れてある。掲載先が決まったら並べる
4. **施設数（193）と対応エリアの言い回し** — 対応エリアの見出し・よくある質問の
   2か所。増えたら書き換える。言い回しは「東京都外」（ご指示 2026-09-21）

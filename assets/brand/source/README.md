# ロゴ画像の置き場所

このフォルダに**元のロゴ画像**を置いてください。
置いたあと、リポジトリ直下で次を実行すると各サイズへ書き出されます。

```powershell
npm run brand:import
```

## 置くファイル

| ファイル名 | 内容 | 必須 |
|---|---|---|
| `logo.png` | 横組みロゴ（マーク＋車寄せナビ＋Driver Entrance Navi） | ● |
| `icon.png` | アプリアイコン（角丸タイルのもの） | 任意 |

- 拡張子は `.png` `.jpg` `.webp` `.svg` のいずれでも構いません。
- **背景を透過した PNG があれば、そちらを置いてください。**
  背景が白のままだと、暗いテーマのときに白い四角が出てしまいます。
- できるだけ**大きい画像**（横 2000px 以上）が望ましいです。
  縮小はできますが、拡大すると粗くなります。
- `icon.png` が無い場合は、ロゴ左側のマーク部分を切り出して
  角丸の濃紺タイルに載せ、アイコンを自動生成します。

## 書き出されるもの

```
assets/brand/
  logo.png          余白を切り詰めた原寸
  logo-h160.png     高さ160px（ログイン画面用）
  logo-h80.png      高さ80px
  logo-h40.png      高さ40px（ヘッダー用）
  icon-1024.png     ストア申請用
  icon-512/192/180/64/32.png
```

管理画面が参照する分は `admin/public/brand/` にも複製されます。

## 図柄について

**元画像の図柄には一切手を加えません。**
行うのは「周囲の余白を切り詰めること」と「拡大縮小」のみです。

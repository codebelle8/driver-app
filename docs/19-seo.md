# 19. 検索（SEO）

ご依頼（2026-11-24）: 上野様から kara さんへ「SEO を」。kara さんのご指示「アプリと紹介サイトの
両方を検索に」。

---

## 方針

**両方を検索に出し、役目を分ける。**

| | 役目 | 題 |
|---|---|---|
| 紹介サイト（kurumayosenavi.com） | サービスの説明。検索から来た人の最初の入口 | 車寄せナビ｜プロドライバーのための車寄せ・エントランス案内 |
| アプリ（app.kurumayosenavi.com） | 使い始める入口（ログイン・新規登録） | 車寄せナビ アプリ｜プロドライバーのための車寄せ・エントランス案内 |

同じ題・同じ説明にすると、「車寄せナビ」で探したときに2つが取り合いになり、どちらも
上がりにくくなる。アプリの題には「アプリ」、説明には「ログイン・新規登録」を入れて分ける。

**アプリで検索に出すのはトップ（/）だけ。** アプリは1枚の html を全部の住所で返し
（`web.output: "single"`）、ログインしていなければどの住所でも入口が出る（AuthGate）。
`/facility/…` や `/mypage` を載せても、中身は同じ入口になる。トップ以外は、配信側の見出し
（`app/vercel.json` の `X-Robots-Tag: noindex`）で載せない。

**この分野は検索する人がもともと少ない。** 結果が出るまで3〜6か月かかる。まず「車寄せナビ」で
探した人に確実に届く土台を作り、次に「〇〇ホテル 車寄せ」のような言葉からの入口を増やす。
会社や乗務員の団体へ直接声をかけるほうが早く人が集まるので、SEO は長く効く下支えと考える。

---

## 進め方（一つずつ。終わるたびに Git へ）

| 順 | すること | 状態 |
|---|---|---|
| 1 | アプリの土台：題・説明・正規の住所・共有の情報・schema.org（WebApplication）・robots.txt・sitemap.xml。トップ以外は載せない | **済**（2026-11-24 公開。本番 `test-seo` 29 / 0） |
| 2 | 紹介サイトの土台：正規の住所・sitemap.xml・schema.org（運営者・サイト・アプリ・よくあるご質問） | **済**（2026-11-24 公開。本番 `test-seo` 46 / 0） |
| 3 | Google Search Console の登録。ドメインごとの登録なら、DNS に1行（TXT）でサイトもアプリも一度に。ConoHa に入れるのは kara さん | |
| 4 | 紹介サイトの「検索に載せない」を4か所とも外す（`index.html`・`vercel.json`・`robots.txt`・`tools/build-legal-pages.mjs` の `NOINDEX`） | |
| 5 | 最初の画面の出る速さを測って直す（紹介サイトは動画と動きが重い） | |
| 6 | 施設ごとのページ（ホテルなど誰でも行ける施設だけ・さわりだけ）。**上野様のご判断が要る** | |

---

## 上野様に伺うこと

1. 施設の名前をサイトに出してよいか。出すなら、ホテルだけ・さわりだけの形でよいか（6 に要る）
2. 紹介サイトの文を、検索される言葉が入るように手直ししてよいか（いまはいただいた文をそのまま）
3. アクセス解析を入れるか。入れるならプライバシーポリシーの書き換えが先
   （「アクセス解析の仕組みを利用していません」と書いてある）。Search Console だけなら書き換えは要らない

## やらないこと

* レジデンス（住まい）の入口の情報を、誰でも見られる形で出す（防犯）
* 中身の薄いページを大量に作る
* リンクをお金で買う

## アプリ（1）

| 場所 | 中身 |
|---|---|
| `app/public/index.html` | 題・説明・正規の住所・共有の情報・schema.org。料金（offers）は書かない（試験提供と有料で変わり、書き換え忘れると古い値段が出る） |
| `app/public/robots.txt` | 読みに来るのを止めない（止めると、トップ以外の noindex も、画面を組み立てる部品も読めなくなる）。sitemap を指す |
| `app/public/sitemap.xml` | トップだけ |
| `app/vercel.json` | トップ以外に `X-Robots-Tag: noindex`。robots.txt と sitemap.xml をアプリの画面に置き換えない |

題はログインしたあとのブラウザのタブにも出るため、どちらの状態でもおかしくない言い方にした
（「ログイン」は題に入れず、説明にだけ入れる）。ホーム画面に置いたときの名前は「車寄せナビ」のまま。

検査: `node tools/test-seo.mjs`（手元は `npx serve -s app/dist/web -l 4291`。4190 は Node の
通信が断る番号）。公開先では、トップ以外が検索に載らないことも確かめる。

## 紹介サイト（2）

| 場所 | 中身 |
|---|---|
| `site/index.html` | 正規の住所。schema.org を1つにまとめた（運営者レベルサーフェス・サイト「車寄せナビ」・アプリ・よくあるご質問） |
| `site/sitemap.xml` | トップと規約類の3ページ。ページを足したらここにも足す |
| `site/robots.txt` | sitemap を指す。作業中のあいだは `Disallow: /` を残す（4段目で外す） |

  * 運営者の住所は schema.org に入れない（特商法の表記には載せているが、検索に渡す情報にまで広げない）
  * **よくあるご質問は、画面の文と一字一句同じにする。** 文を変えたら schema.org も直す
    （`tools/test-seo.mjs` が食い違いを見つける）。「どの地域に対応していますか？」は入れない
    （答えの施設数を開いたときに読み直すため、書くとすぐ古くなる）
  * よくあるご質問の書き方は、2023年から検索結果での特別な出し方の対象が国や医療のサイトに
    絞られており、このサイトでは見た目は変わらない。中身を伝える助けとして入れている
  * 題と説明文は、いただいた文のまま（手直しは上野様のご判断待ち）

検査: `node tools/test-seo.mjs [アプリ] [紹介サイト]`（手元は `npx serve -l 4300 site`）。

## はじめに

「車寄せナビ」の規約類として、次の三点のたたき台をご用意しました。

| | 何のためのものか | 掲示 |
|---|---|---|
| A | 利用規約 | 必須 |
| B | プライバシーポリシー | 必須（メールアドレス等をお預かりするため） |
| C | 特定商取引法に基づく表記 | **継続してお金をいただくために必須** |

**【　】で囲んだところは、ご記入いただく箇所です。**
埋めていただきたい項目は、末尾にまとめてあります。

**最終的な文面は、弁護士など専門家の方に一度ご確認いただくことを
強くお勧めいたします。** 特に返金の条件・免責の範囲・管轄裁判所の
三点は、事業の実情に合わせた判断が要ります。こちらでお作りできるのは
「よくある形」までで、事業の実情を織り込んだ判断は致しかねます。

  **お支払いになるのが乗務員の方ご本人と決まったため、消費者契約法が
  当てはまります。** 事業者どうしの取引より、書けることが狭くなります。
  ご確認はいっそう大切になります。

**継続課金を始める場合、この三点の掲示は「あったほうがよい」では
なく「無いと始められない」ものになります。** カード会社および決済
代行会社の審査では、利用規約・特定商取引法に基づく表記・プライバシー
ポリシーの掲示が確認されます。掲示のないサイトは、審査を通りません。

  対応していません。事実をお伝えしたうえで、iD をお使いの方には
  「そのカードをご登録ください」とご案内するのが現実的です。

### 口座振替について（ご要望の軸）

**どの銀行が使えるかは、決済代行会社との契約で決まります。**
「すべての金融機関」とお約束できる会社はありません。実務上は、
次の範囲を確認していただくことになります。

| 区分 | 確認する点 |
|---|---|
| 都市銀行 | ほぼ全社が対応します |
| 地方銀行・第二地方銀行 | **会社によって数に差が出ます。ここが要確認** |
| 信用金庫・信用組合 | 同上。対応数の差がいちばん大きい区分です |
| ゆうちょ銀行 | 別枠の扱いになることがあります。**別料金の場合もあります** |
| ネット銀行 | **対応しないことが多い**（口座振替の仕組みを持たない銀行があります） |

  乗務員の方がどの銀行をお使いかは分かりません。**対応する
  金融機関の数が多い会社を選ぶことが、そのまま「使える方が
  多い」ことになります。**

**口座振替には、始めるまでに時間がかかります。**

| | |
|---|---|
| 口座のご登録 | 画面で入力（Web口座振替受付）。**銀行によっては書面での手続きが要ります** |
| 使えるようになるまで | **2〜6週間ほど**（金融機関と決済代行会社によります） |
| その間のお支払い | **別の方法が要ります。** カードか銀行振込で最初の期間ぶんを頂戴し、次の更新から口座振替に切り替えるのが通例です |
| 引き落とし日 | **毎月の決まった日**（27日など）。期間の満了日とは一致しません |

  この最後の一点が、規約の第7条第6項・第7項です。
  **「1年プランを4月10日に申し込んだから、翌年4月10日に引き落とす」
  という形にはできません。** 決まった日にしか引き落とせないため、
  ずれるぶんは利用期間を延ばして調整する、と書いてあります。

### 手数料について

決済代行会社との契約で決まるため、当方では確定できません。
おおよその目安は次のとおりですが、**必ずご契約前にご確認ください。**

| 方法 | 手数料の目安 | 1年プラン 40,000円 の場合 |
|---|---|---|
| **口座振替** | **1件あたり数十円〜数百円（定額）** | **数百円** |
| クレジットカード | 3%台後半（料率） | 1,400〜1,500円ほど |
| コード決済 | 3%台後半（料率） | 同上 |
| 銀行振込（いまの方法） | 0円（お客様負担） | 0円 |

  **口座振替は定額、カードは料率です。** ここが効きます。
  1年 40,000円 では、カードのほうが口座振替より1,000円ほど多く
  引かれます。月々4,000円では差は百数十円まで縮まります。
  **長い期間のプランを勧めるほど、口座振替の利点が大きくなります。**

  ただし、口座振替には**月額の基本料金**（数千円程度）を求める会社が
  あります。会員数が少ないうちは、基本料金のほうが手数料の差より
  大きくなることがあります。**会員数の見込みと合わせてご判断ください。**

### 進め方のご提案

1. **口座振替とカードの両方**に対応する決済代行会社を選ぶ
2. **地方銀行・信用金庫の対応数**と、**月額の基本料金**を各社で比べる
3. 審査（1〜2週間）を申し込む。**この文書の三点の掲示が必要です**
4. まずカードで始め、口座振替の登録が済んだ方から順に切り替える

  審査では、利用規約・特定商取引法に基づく表記・プライバシー
  ポリシーの掲示が確認されます。掲示のないサイトは通りません。
  **先に掲示を済ませておくほど、話が早く進みます。**

## はじめに

「車寄せナビ」の規約類として、次の三点のたたき台をご用意しました。

| | 何のためのものか | 掲示 |
|---|---|---|
| A | 利用規約 | 必須 |
| B | プライバシーポリシー | 必須（メールアドレス等をお預かりするため） |
| C | 特定商取引法に基づく表記 | **継続してお金をいただくために必須** |

**【　】で囲んだところは、ご記入いただく箇所です。**
まだ決まっていない項目は、後ろの「まだ決まっていないこと」にまとめてあります。

**最終的な文面は、弁護士など専門家の方に一度ご確認いただくことを
強くお勧めいたします。** 特に返金の条件・免責の範囲・管轄裁判所の
三点は、事業の実情に合わせた判断が要ります。こちらでお作りできるのは
「よくある形」までで、事業の実情を織り込んだ判断は致しかねます。

  **お支払いになるのが乗務員の方ご本人と決まったため、消費者契約法が
  当てはまります。** 事業者どうしの取引より、書けることが狭くなります。
  ご確認はいっそう大切になります。

**継続課金を始める場合、この三点の掲示は「あったほうがよい」では
なく「無いと始められない」ものになります。** カード会社および決済
代行会社の審査では、利用規約・特定商取引法に基づく表記・プライバシー
ポリシーの掲示が確認されます。掲示のないサイトは、審査を通りません。

## A. 利用規約

**第1条（適用）**

運営者は屋号の「レベルサーフェス」で書いています。お支払いになるのは

**第3条（アカウントの管理）**

第5項〜第7項は 2026-09-30 に足しました。地下の車寄せなど、電波の
届かない場所で開いても使えるようにしたためです。無料期間・利用期間の

第6項の日数は、いま30日です（管理画面の「サイト設定」で変更可）。
毎日お使いの方なら、30日のあいだに必ず一度は電波のある場所で開く

方や別の端末へ移った方が、圏外のまま使い続けられます。

第7項は、ログアウトすると電波が戻るまで入り直せなくなるためです。

**第4条（試験提供期間）**

**試験提供（β版）の期間中は、すべて無料です**（2026-10-04 のご回答）。
有料化のお知らせは **30日前** までに出します（第4項）。お知らせだけで
自動的に有料へ移ることはありません（第5項）。

試験提供を終えた時点で、この条は削除してください。残したままに
すると「いまも無料のはず」と読めてしまいます。

**第6項（試験提供中は無料期間が過ぎても使える）は、いまのアプリと
食い違っています。** アプリは、登録から1か月で先へ進めなくなる作りの

有料化のあとに登録された方は、登録から1か月間無料です。無料期間中に
有料のお手続きをされても、残りの日数は失われません（第2項）。

  差し替えます
* 3か月・6か月のプランは、ご回答に無かったため外しました
* **「税込」と書いています。** 乗務員の方（消費者）へお示しする価格は、

| 6か月 | 2,000円 |
| 3か月 | 500円 |
| 2か月以下 | 返金なし |

ご説明に無かったところを、次のとおり補っています。

* 残りの月数は、おやめになった日の翌日から満了日までで数え、

## 決済手段について（第7条の表を埋めるために）

ご要望は「出来るだけ多くの決済システム」であり、そのなかでも
**各種の銀行口座からお引き落としできること（口座振替）**を軸に
置いております。**規約の第7条の表は、ここが決まらないと確定できません。**

### 継続課金（自動更新）に使えるかどうか

| 方法 | 自動更新 | 備考 |
|---|---|---|
| **口座振替** | **できます** | **ご要望の軸。** 手数料は1件ごとの定額です。12か月の一括払いのように、金額が大きいほど割安になります |
| クレジットカード／デビットカード | **できます** | もっとも確実で、始めるのも早い。どの決済代行会社も対応します |
| 銀行振込 | できません | いま動いている方法。都度のお振込み |
| PayPay | **できる場合があります** | 継続課金の仕組みはありますが、扱える決済代行会社が限られます |
| d払い・auかんたん決済・ソフトバンクまとめて支払い | **できる場合があります** | 同上 |
| 交通系ICカード（Suica、PASMO 等） | **できません** | 前払式の残高で、オンラインの継続課金には使えません。実店舗のタッチ決済向けです |
| iD、QUICPay | **できません** | カードに紐づく実店舗向けの方式です。**ただし、その元になっているカードをそのまま登録いただければ、同じカードから引き落とせます** |

  **Suica と iD は、ご期待に沿えません。** 仕組みそのものが
  「その場で1回払う」ためのもので、毎月の自動引き落としには
  対応していません。事実をお伝えしたうえで、iD をお使いの方には
  「そのカードをご登録ください」とご案内するのが現実的です。

### 口座振替について（ご要望の軸）

**どの銀行が使えるかは、決済代行会社との契約で決まります。**
「すべての金融機関」とお約束できる会社はありません。実務上は、
次の範囲を確認していただくことになります。

| 区分 | 確認する点 |
|---|---|
| 都市銀行 | ほぼ全社が対応します |
| 地方銀行・第二地方銀行 | **会社によって数に差が出ます。ここが要確認** |
| 信用金庫・信用組合 | 同上。対応数の差がいちばん大きい区分です |
| ゆうちょ銀行 | 別枠の扱いになることがあります。**別料金の場合もあります** |
| ネット銀行 | **対応しないことが多い**（口座振替の仕組みを持たない銀行があります） |

  乗務員の方がどの銀行をお使いかは分かりません。**対応する
  金融機関の数が多い会社を選ぶことが、そのまま「使える方が
  多い」ことになります。**

**口座振替には、始めるまでに時間がかかります。**

| | |
|---|---|
| 口座のご登録 | 画面で入力（Web口座振替受付）。**銀行によっては書面での手続きが要ります** |
| 使えるようになるまで | **2〜6週間ほど**（金融機関と決済代行会社によります） |
| その間のお支払い | **別の方法が要ります。** カードか銀行振込で最初の期間ぶんを頂戴し、次の更新から口座振替に切り替えるのが通例です |
| 引き落とし日 | **毎月の決まった日**（ご希望は25日）。期間の満了日とは一致しません |

  この最後の一点が、規約の第7条第6項・第7項です。
  **「12か月プランを4月10日に申し込んだから、翌年4月10日に引き落とす」
  という形にはできません。** 決まった日にしか引き落とせないため、
  ずれるぶんは利用期間を延ばして調整する、と書いてあります。

### 手数料について

決済代行会社との契約で決まるため、当方では確定できません。
おおよその目安は次のとおりですが、**必ずご契約前にご確認ください。**

| 方法 | 手数料の目安 | 1か月 600円 の場合 | 12か月 5,000円 の場合 |
|---|---|---|---|
| **口座振替** | **1件あたり数十円〜数百円（定額）** | 数十円〜数百円 | 数十円〜数百円 |
| クレジットカード | 3%台後半（料率） | 20円台 | 190円前後 |
| コード決済 | 3%台後半（料率） | 同上 | 同上 |
| 銀行振込（いまの方法） | 0円（お客様負担） | 0円 | 0円 |

  **料金を下げられたことで、以前の見立てが変わります。** 口座振替は
  1件ごとの定額ですので、**1か月 600円では、手数料が料金の1割から
  3割ほどになることがあります。** カードは料率ですので、20円台で
  済みます。12か月 5,000円では、両者はおおむね近くなります。

  **口座振替は、12か月の一括払い向き**とお考えいただくのがよいと
  存じます。1か月のプランは、カードやコード決済を中心にされるほうが
  無理がありません。

  また、口座振替には**月額の基本料金**（数千円程度）を求める会社が
  あります。会員数が少ないうちは、基本料金のほうが手数料の差より
  大きくなることがあります。**会員数の見込みと合わせてご判断ください。**

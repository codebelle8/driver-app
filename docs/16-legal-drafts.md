作成 2026-09-15

開発側の覚え書きは `docs/13-legal-templates.md` にあります。

## はじめに

「車寄せナビ」の規約類として、次の三点のたたき台をご用意しました。

| | 何のためのものか | 掲示 |
|---|---|---|
| A | 利用規約 | 必須 |
| B | プライバシーポリシー | 必須（メールアドレス等をお預かりするため） |
| C | 特定商取引法に基づく表記 | **継続してお金をいただくために必須** |

**【　】で囲んだところは、御社の情報を入れていただく箇所です。**
埋めていただきたい項目は、末尾にまとめてあります。

**最終的な文面は、弁護士など専門家の方に一度ご確認いただくことを
強くお勧めいたします。** 特に返金の条件・免責の範囲・管轄裁判所の
三点は、事業の実情に合わせた判断が要ります。こちらでお作りできるのは
「よくある形」までで、御社の事情を織り込んだ判断は致しかねます。

## いまの作りに合わせて書いています

事実と違うところがあれば、お知らせください。書き直します。

| 事項 | いまの作り |
|---|---|
| 提供の形 | ブラウザで動くアプリ（インストール不要。ホーム画面へ追加も可） |
| 登録 | メールアドレスとパスワード |
| 無料期間 | 登録から**1か月** |
| 料金 | 1か月 4,000円／3か月 11,000円／6か月 21,000円／1年 40,000円 |
| お支払い | **銀行振込**（会員番号を振込名義に添えていただく） |
| 入金の確認 | 通帳をご覧になり、管理画面で「入金を確認した」を押す |
| 端末 | **1つのアカウントにつき1台**。新しく入った端末が有効になり、前の端末は出る |
| 退会 | アプリから退会でき、アカウントと顔写真は消える |
| 保存先 | Supabase（データベース）と Vercel（配信）。**いずれも海外のサーバー** |

**お預かりしている情報**（これで全部です）

* メールアドレス、パスワード（暗号化して保存。当方も元の文字は見られません）
* 表示名、顔写真（ご本人が入れた場合のみ）
* お選びになった料金の種類と、選んだ日
* お気に入り、閲覧履歴
* 端末を見分けるための符号（**端末そのものの情報ではなく、こちらで振った乱数**）
* 通知の配信先（通知を許可した場合のみ）

1. 利用者は、メールアドレスおよびパスワードを自己の責任で管理する

2. **1つのアカウントで同時に利用できる端末は1台です。** 別の端末で

4. アカウントを用いて行われた行為は、利用者本人の行為とみなします。

**第4条（無料期間および利用料金）**

1. 登録日から**1か月間**は、無料でご利用いただけます。
2. 無料期間の経過後は、次のいずれかをお選びいただきます。

5. **当社が入金を確認した時点から、お選びの期間のご利用を開始します。**
6. 期間の満了後も引き続きご利用になる場合は、あらためてお振込み

## 埋めていただきたい項目

この5つが分かれば、三点とも清書できます。

1. **運営者名** — 個人事業か、法人か（法人の場合は正式名称）
2. **所在地** — 特定商取引法で必須です
3. **電話番号** — 同上（「請求があれば開示」とする方法もあります）
4. **お問い合わせ用のメールアドレス** — 個人のものとは分けることを
   お勧めします
5. **料金は税込か税別か**

## 専門家にご確認いただきたい判断

1. **返金および中途解約の扱い** — 3か月・6か月・1年のプランは
   前払いです。途中で退会された場合の扱いを決めておく必要があります
2. **免責の書きぶりと、責任の上限額**
3. **管轄裁判所**

## 掲載について

三点とも、御社のホームページなどに掲載し、そのURLを管理画面の
「サイト設定」にご入力ください。アプリの「このアプリについて」から
開けるようになります。

掲載先がまだお決まりでなければ、ページの作成と公開もこちらで承ります。

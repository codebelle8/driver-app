# 利用規約

**第1条（適用）**

1. 本規約は、レベルサーフェス（以下「当方」といいます）が提供する
   「車寄せナビ」（以下「本サービス」といいます）の利用条件を定める
   ものです。
2. 利用者は、本規約に同意のうえ、本サービスを利用するものとします。
3. 本サービスは、旅客自動車運送事業に従事する乗務員本人の利用を
   予定しています。事業者が所属する乗務員のために一括して申し込む
   場合は、別途当方との協議によるものとします。

**第2条（会員登録）**

1. 登録を希望する者は、本規約およびプライバシーポリシーに同意のうえ、
   当方の定める方法により登録を申請するものとします。
2. 当方は、次の各号のいずれかに該当する場合、登録を承認しないことが
   あります。
   - 申請内容に虚偽がある場合
   - 過去に本規約に違反したことがある場合
   - その他、当方が不適当と判断した場合

**第3条（アカウントの管理）**

1. 利用者は、メールアドレスおよびパスワードを自己の責任において
   管理するものとします。
2. 1つのアカウントで同時に利用できる端末は1台とします。別の端末で
   ログインした場合、先に使用していた端末はログアウトされます。
3. 利用者は、アカウントを第三者に譲渡し、貸与し、または共有しては
   なりません。
4. アカウントを用いて行われた行為は、利用者本人の行為とみなします。
5. 通信ができない場所においては、当方は、利用者の端末に保存された
   会員情報（当方が最後に確認した時点のものであり、利用の可否、無料
   期間および利用期間を含みます）に基づいて本サービスを提供し、通信が
   回復した後に改めて確認します。利用の停止、他の端末でのログインその
   他の変更は、当該確認の時点から反映されます。
6. 当方が前項の確認を最後に行った時点から当方が定める日数を経過した
   場合、利用者は、通信ができる場所で改めて確認が行われるまでの間、
   本サービスを利用することができません。
7. 通信ができない場所においては、ログアウトを行うことができません。

**第4条（試験提供期間）**

1. 本サービスは、現在、試験提供の期間にあります。
2. 試験提供の期間中、当方は利用料金を請求しません。
3. 試験提供の期間中、当方は、本サービスの内容、画面および機能を、
   予告なく変更し、または中止することがあります。
4. 当方は、試験提供の期間を終了し有料での提供を開始する場合、開始の
   30日前までに、本サービス上の掲示または利用者が登録した
   メールアドレスへの送信により、その旨を通知します。
5. 前項の通知により、利用者が自動的に有料の利用に移行することは
   ありません。有料の利用は、利用者が第7条に定める手続きを行った
   時点から開始します。
6. 試験提供の期間中は、第5条に定める無料期間が経過した後も、利用者は
   引き続き本サービスを利用することができます。
7. 試験提供の期間を終了し有料での提供を開始する時点で、第5条第1項に
   定める無料期間を経過している利用者は、有料での提供を開始した日から
   1か月間、無料で本サービスを利用することができます。

**第5条（無料期間）**

1. 利用者は、登録日から1か月間、無料で本サービスを利用することが
   できます。
2. 無料期間中に有料の利用を開始した場合、無料期間の残存期間は消滅せず、
   当該残存日数に利用者が選択した期間を加えた期間を、利用期間と
   します。
3. 無料期間の経過後、有料の利用を開始しない場合、利用者は本サービスの
   機能の一部を利用することができなくなります。

**第6条（利用料金）**

1. 本サービスの利用料金は、次のとおりとします（いずれも税込）。

   | 期間 | 料金 |
   |---|---|
   | 1か月 | 600円 |
   | 12か月（一括払い） | 5,000円 |

2. 利用料金は前払いとします。
3. 通信料その他、本サービスの利用に必要となる費用は、利用者の負担と
   します。
4. 当方は、施設情報の調査に協力する利用者、本サービスの運営に従事する
   利用者その他当方が別に定める利用者について、利用料金の全部または
   一部を免除することがあります。
5. 前項のほか、第14条第6項に定める情報提供の上位者は、同項に定める
   期間、利用料金を要しません。

**第7条（支払方法）**

1. 利用料金の支払は、当方が定め、本サービス上に表示する方法によります。
2. 前項の支払方法のうち、口座振替、クレジットカード、デビットカード、
   コード決済および通信料金合算による支払は、当方が委託する決済代行
   会社を通じて処理されます。利用者は、当該決済代行会社の定める規約に
   従うものとします。
3. 当方は、預貯金口座の番号、クレジットカード番号その他の決済情報を
   保有しません。これらは決済代行会社および金融機関が管理します。
4. 口座振替を利用することができる金融機関は、本サービス上に表示します。
5. 口座振替を利用する場合、利用者は、あらかじめ本サービス上の所定の
   方法により口座の登録を行うものとします。登録から利用が可能となる
   までには、本サービス上に表示する期間を要し、当該期間中の支払は他の
   方法によります。
6. 口座振替による引落しは、毎月25日（当該日が金融機関の休業日に
   あたる場合は翌営業日）に行います。
7. 前項により引落日と利用期間の満了日が一致しない場合、当方は、利用者に
   不利とならないよう利用期間を調整します。
8. 利用者が登録した口座を変更する場合、本サービス上で変更の手続を
   行うものとします。変更が反映されるまでの間、従前の口座から引落しが
   行われることがあります。
9. 銀行振込による場合、振込手数料は利用者の負担とします。利用者は、
   振込後、本サービス上の所定の方法により当方へ通知するものとし、
   当方が入金を確認した時点から、利用者が選択した期間の利用を開始
   します。
10. 自動更新に対応しない支払方法を選択した場合、利用者は、期間の満了後
    引き続き本サービスを利用するために、あらためて手続を行うものと
    します。

**第8条（継続課金および自動更新）**

1. 自動更新に対応する支払方法を選択した場合、利用者が選択した期間が
   満了する日に、同一の期間および同一の料金で自動的に更新され、
   利用者が登録した支払方法により決済されます。
2. 更新に係る決済は、満了日に行います。ただし、口座振替による場合は
   第7条第6項に定める引落日に行い、その他の方法による場合も、決済
   代行会社の処理により前後することがあります。
3. 当方は、更新に先立ち、更新日および金額を、本サービス上の通知または
   利用者が登録したメールアドレスへの送信により、利用者へ通知します。
4. 利用者は、更新を希望しない場合、満了日の前日までに第10条に定める
   手続を行うものとします。
5. 利用者は、支払方法に関する情報に変更が生じた場合、速やかに本サービス
   上で登録内容を更新するものとします。

**第9条（決済不能の場合の取扱い）**

1. 預貯金口座の残高不足、口座の解約、クレジットカードの有効期限切れ
   その他の事由により更新に係る決済ができなかった場合、当方は、本サー
   ビス上の通知または利用者が登録したメールアドレスへの送信により利用
   者へその旨を通知し、7日間、再度の決済または支払方法の変更を待つもの
   とします。
2. 前項の期間内に支払が確認できない場合、当方は本サービスの提供を
   停止することがあります。
3. 前項による停止の後に支払が確認された場合、当方は本サービスの提供を
   再開します。この場合において、停止した期間に相当する期間を延長する
   ことはありません。

**第10条（解約および自動更新の停止）**

1. 利用者は、本サービス上の所定の方法により、いつでも自動更新を停止
   することができます。ただし、口座振替による場合において、金融機関へ
   の請求が既に行われているときは、当該回の引落しを停止できないことが
   あります。この場合、当方は、引き落とした金額を返金し、または利用
   期間に充当します。
2. 自動更新を停止した場合においても、利用者は、既に支払を了した期間の
   満了日までは、引き続き本サービスを利用することができます。
3. 満了日の経過により、利用者は本サービスの有料の機能を利用することが
   できなくなります。
4. 自動更新の停止は、第19条に定める退会とは異なります。退会を希望する
   場合、利用者は別途退会の手続を行うものとします。
5. 利用者は、本サービス上の所定の方法により、利用期間の途中で有料の
   利用を解約することができます（以下「中途解約」といいます）。中途
   解約をした場合、利用者は、その時点から本サービスの有料の機能を利用
   することができなくなります。中途解約に伴う返金は、第11条によります。

**第11条（返金）**

1. 1か月の利用料金は、返金しません。
2. 12か月分の利用料金を一括で支払った利用者が、中途解約をし、または
   退会した場合、当方は、残存月数から2か月を差し引いた月数に500円を
   乗じた額を返金します。
3. 前項の残存月数は、中途解約または退会の日の翌日から利用期間の満了日
   までの期間の月数とし、1か月に満たない端数は切り捨てます。残存月数
   が3か月に満たない場合、返金は行いません。
4. 第2項の500円は、12か月分の利用料金5,000円を10か月で除した額であり、
   同項の2か月は、一括払いによる割引（2か月分）に相当するものです。
5. 返金は、原則として、利用者が支払に用いた方法により行います。
6. 前各項にかかわらず、当方の責めに帰すべき事由により本サービスの提供
   が7日以上継続して停止した場合、当方は、停止した期間に相当する金額を
   返金し、または利用期間を延長します。

**第12条（料金および支払方法の変更）**

1. 当方は、利用料金を変更することがあります。
2. 前項により変更する場合、当方は、変更日の30日前までに、
   本サービス上の掲示または利用者が登録したメールアドレスへの送信に
   より、利用者へ通知します。
3. 変更後の利用料金は、前項の通知の後に到来する最初の更新に係る料金
   から適用します。既に支払を了した期間には適用しません。
4. 当方は、支払方法の追加、変更または廃止を行うことがあります。
   廃止する場合、前項と同様に通知します。

3. アカウントを第三者と共有する行為
4. 本サービスの運営を妨げる行為、または不正にアクセスする行為
5. 他人の支払方法を無断で使用する行為
6. 事実と異なる情報を、故意に送り、または書き込む行為
7. 他人の氏名、連絡先、顔写真、自動車の登録番号その他特定の個人を

11. その他、当方が不適当と判断する行為

1. 利用者は、本サービス上の所定の方法により、施設の車寄せ、入口、
   注意事項その他の情報（写真を含みます。以下「提供情報」といいます）を

   含まれる写真について、当方へ提供するために必要な権利を有している
   ことを保証するものとします。
3. 利用者は、提供情報に、人の顔、自動車の登録番号その他特定の個人を
   識別できる情報を含めないものとします。これらが含まれていた場合、
   当方は、当該部分を加工し、または当該提供情報を利用しないことが
   あります。
4. 当方は、提供情報を審査し、採用するか否かを決定します。採用した
   提供情報は、当方の判断により、本サービスの施設情報に反映します。

   対し、提供情報について著作者人格権を行使しないものとします。
6. 当方は、日本時間による月ごとに、当該月に採用した提供情報の件数

   件数が当方の定める件数以上である利用者のうち、上位から当方の定める

   利用することができます。既に利用料金を支払っている利用者については、
   利用期間を1か月延長します。

8. 当方は、翌月の初めに前月の順位を確定します。確定した後に採用を
   取り消した場合においても、確定した結果は変わりません。
9. 第6項の件数および人数は、本サービス上に表示します。当方は、
   あらかじめ本サービス上に掲示することにより、これらを変更し、または
   第6項の取扱いを終了することがあります。この場合においても、既に
   確定した結果は変わりません。
10. 第6項による利益は、他人に譲渡し、または金銭に換えることは
    できません。
11. 順位は、利用者の表示名および採用件数とともに、ほかの利用者に表示
    されます。利用者は、本サービス上の設定により、表示名に代えて
    「匿名の会員」と表示させることができます。

**第15条（チャット）**

1. 当方は、利用者が書き込み（画像を含みます。以下同じ）を行い、ほかの
   利用者と情報を交換するための機能（以下「チャット」といいます）を
   提供します。チャットの書き込みは、
   すべての利用者が閲覧することができます。当方は、利用者どうしが
   1対1で通信する機能を提供しません。
2. チャットの書き込みには、書き込んだ利用者の表示名および顔写真が
   添えて表示されます。
3. 利用者がアプリを開いている間、チャットにおいて、当該利用者が
   オンラインであることがほかの利用者に表示されます。利用者は、
   本サービス上の設定により、これを表示しないことができます。
4. 書き込みの内容についての責任は、書き込んだ利用者が負います。
   利用者は、自らの書き込みをいつでも削除することができます。
5. 当方は、書き込みが本規約に違反し、またはそのおそれがあると判断した
   場合、事前の通知なく、当該書き込みを非表示にし、または当該利用者に
   よる書き込みを停止することがあります。当方は、非表示とした書き込みを、
   対応の記録として保存します。
6. 利用者は、本規約に違反すると考える書き込みを、本サービス上の所定の
   方法により当方へ通報することができます。当方は、通報した利用者を、
   ほかの利用者に開示しません。
7. 当方は、一定の時間内に行うことのできる書き込みの数、1件の書き込みの
   文字数、および書き込みに添えることのできる画像の数に上限を設ける
   ことがあります。
8. 当方は、書き込みを常時監視する義務を負いません。
9. 書き込みは、書き込んだ日から90日を経過すると、チャットに表示されなく
   なります。当方は、本規約に違反する書き込みへの対応のため、書き込みを、
   書き込んだ日から1年を経過するまで保存し、その後削除します。

1. 当方は、利用者への事前の通知により、本サービスの内容を変更し、
   またはその提供を終了することがあります。
2. 次の各号のいずれかに該当する場合、当方は、事前の通知なく本サービスの

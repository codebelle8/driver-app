# 利用規約

**第1条（適用）**

1. 本規約は、【　運営者氏名　】（以下「当方」といいます）が提供する
   「車寄せナビ」（以下「本サービス」といいます）の利用条件を定める
   ものです。
2. 利用者は、本規約に同意のうえ、本サービスを利用するものとします。
3. 本サービスは、旅客自動車運送事業に従事する乗務員本人の利用を
   予定しています。事業者が所属する乗務員のために一括して申し込む
   場合は、別途当方との協議によるものとします。

**第2条（会員登録）**

1. 登録を希望する者は、本規約に同意のうえ、当方の定める方法により
   登録を申請するものとします。
2. 当方は、次の各号のいずれかに該当する場合、登録を承認しないことが
   あります。
   - 申請内容に虚偽がある場合
   - 過去に本規約に違反したことがある場合
   - その他、当方が不適当と判断した場合

**第3条（アカウントの管理）**

1. 利用者は、メールアドレスおよびパスワードを自己の責任において
   管理するものとします。
2. 1つのアカウントで同時に利用できる端末は1台とします。別の端末で
   ログインした場合、先に使用していた端末はログアウトされます。
3. 利用者は、アカウントを第三者に譲渡し、貸与し、または共有しては
   なりません。
4. アカウントを用いて行われた行為は、利用者本人の行為とみなします。

**第4条（試験提供期間）**

1. 本サービスは、現在、試験提供の期間にあります。
2. 試験提供の期間中、当方は利用料金を請求しません。
3. 試験提供の期間中、当方は、本サービスの内容、画面および機能を、
   予告なく変更し、または中止することがあります。
4. 当方は、試験提供の期間を終了し有料での提供を開始する場合、開始の
   【　　】日前までに、本サービス上の掲示または利用者が登録した
   メールアドレスへの送信により、その旨を通知します。
5. 前項の通知により、利用者が自動的に有料の利用に移行することは
   ありません。有料の利用は、利用者が第7条に定める手続きを行った
   時点から開始します。
6. 試験提供の期間中は、第5条に定める無料期間が経過した後も、利用者は
   引き続き本サービスを利用することができます。

**第5条（無料期間）**

1. 利用者は、登録日から1か月間、無料で本サービスを利用することが
   できます。
2. 無料期間中に有料の利用を開始した場合、無料期間の残存期間は消滅せず、
   当該残存日数に利用者が選択した期間を加えた期間を、利用期間と
   します。
3. 無料期間の経過後、有料の利用を開始しない場合、利用者は本サービスの
   機能の一部を利用することができなくなります。

**第6条（利用料金）**

1. 本サービスの利用料金は、次のとおりとします。

   | 期間 | 料金 |
   |---|---|
   | 1か月 | 4,000円（【　税込／税別　】） |
   | 3か月 | 11,000円（【　税込／税別　】） |
   | 6か月 | 21,000円（【　税込／税別　】） |
   | 1年 | 40,000円（【　税込／税別　】） |

2. 利用料金は前払いとします。
3. 通信料その他、本サービスの利用に必要となる費用は、利用者の負担と
   します。

**第7条（支払方法）**

1. 利用料金の支払は、当方が定め、本サービス上に表示する方法によります。
2. 前項の支払方法のうち、口座振替、クレジットカード、デビットカード、
   コード決済および通信料金合算による支払は、当方が委託する決済代行
   会社を通じて処理されます。利用者は、当該決済代行会社の定める規約に
   従うものとします。
3. 当方は、預貯金口座の番号、クレジットカード番号その他の決済情報を
   保有しません。これらは決済代行会社および金融機関が管理します。
4. 口座振替を利用することができる金融機関は、本サービス上に表示します。
5. 口座振替を利用する場合、利用者は、あらかじめ本サービス上の所定の
   方法により口座の登録を行うものとします。登録から利用が可能となる
   までに【　　】週間を要し、当該期間中の支払は他の方法によります。
6. 口座振替による引落しは、毎月【　　】日（当該日が金融機関の休業日に
   あたる場合は翌営業日）に行います。
7. 前項により引落日と利用期間の満了日が一致しない場合、当方は、利用者に
   不利とならないよう利用期間を調整します。
8. 利用者が登録した口座を変更する場合、本サービス上で変更の手続を
   行うものとします。変更が反映されるまでの間、従前の口座から引落しが
   行われることがあります。
9. 銀行振込による場合、振込手数料は利用者の負担とします。利用者は、
   振込後、本サービス上の所定の方法により当方へ通知するものとし、
   当方が入金を確認した時点から、利用者が選択した期間の利用を開始
   します。
10. 自動更新に対応しない支払方法を選択した場合、利用者は、期間の満了後
    引き続き本サービスを利用するために、あらためて手続を行うものと
    します。

**第8条（継続課金および自動更新）**

1. 自動更新に対応する支払方法を選択した場合、利用者が選択した期間が
   満了する日に、同一の期間および同一の料金で自動的に更新され、
   利用者が登録した支払方法により決済されます。
2. 更新に係る決済は、満了日またはその前後【　　】日以内に行います。
   口座振替による場合は、第7条第6項に定める引落日によります。
3. 当方は、更新に先立ち、更新日および金額を、本サービス上の通知または
   利用者が登録したメールアドレスへの送信により、利用者へ通知します。
4. 利用者は、更新を希望しない場合、満了日の前日までに第10条に定める
   手続を行うものとします。
5. 利用者は、支払方法に関する情報に変更が生じた場合、速やかに本サービス
   上で登録内容を更新するものとします。

**第9条（決済不能の場合の取扱い）**

1. 預貯金口座の残高不足、口座の解約、クレジットカードの有効期限切れ
   その他の事由により更新に係る決済ができなかった場合、当方は利用者へ
   その旨を通知し、【　　】日間、再度の決済または支払方法の変更を
   待つものとします。
2. 前項の期間内に支払が確認できない場合、当方は本サービスの提供を
   停止することがあります。
3. 前項による停止の後に支払が確認された場合、当方は本サービスの提供を
   再開します。この場合において、停止した期間に相当する期間を延長する
   ことはありません。

**第10条（解約および自動更新の停止）**

1. 利用者は、本サービス上の所定の方法により、いつでも自動更新を停止
   することができます。ただし、口座振替による場合において、金融機関へ
   の請求が既に行われているときは、当該回の引落しを停止できないことが
   あります。この場合、当方は、引き落とした金額を返金し、または利用
   期間に充当します。
2. 自動更新を停止した場合においても、利用者は、既に支払を了した期間の
   満了日までは、引き続き本サービスを利用することができます。
3. 満了日の経過により、利用者は本サービスの有料の機能を利用することが
   できなくなります。
4. 自動更新の停止は、第17条に定める退会とは異なります。退会を希望する
   場合、利用者は別途退会の手続を行うものとします。

**第11条（返金および中途解約）**

1. 利用者が支払を了した利用料金は、返金しません。
2. 期間の途中で解約し、または退会した場合においても、残存期間に相当
   する金額の返金は行いません。
3. 前2項にかかわらず、当方の責めに帰すべき事由により本サービスの提供が
   【　　】日以上継続して停止した場合、当方は、停止した期間に相当する
   金額を返金し、または利用期間を延長します。

**第12条（料金および支払方法の変更）**

1. 当方は、利用料金を変更することがあります。
2. 前項により変更する場合、当方は、変更日の【　　】日前までに、
   本サービス上の掲示または利用者が登録したメールアドレスへの送信に
   より、利用者へ通知します。
3. 変更後の利用料金は、前項の通知の後に到来する最初の更新に係る料金
   から適用します。既に支払を了した期間には適用しません。
4. 当方は、支払方法の追加、変更または廃止を行うことがあります。
   廃止する場合、前項と同様に通知します。

**第13条（禁止事項）**

利用者は、本サービスの利用にあたり、次の各号の行為を行ってはなりません。

1. 法令または公序良俗に違反する行為
2. 本サービスの内容（施設情報、写真および案内図を含みます）を、当方の
   許諾なく複製し、転載し、販売し、または配布する行為
3. アカウントを第三者と共有する行為
4. 本サービスの運営を妨げる行為、または不正にアクセスする行為
5. 他人の支払方法を無断で使用する行為
6. その他、当方が不適当と判断する行為

**第14条（本サービスの内容および免責）**

1. 本サービスが表示する車寄せ、入口および経路は、案内の目安です。
   現地の標識、警備員の指示、交通規制および道路交通法の定めが優先
   します。
2. 施設の改修、工事、催事その他の事由により、実際の状況が本サービスの
   内容と異なる場合があります。
3. 本サービスは、施設情報を利用者の端末に保存し、通信ができない場所
   においても表示できるようにしています。この場合において表示される
   内容は、最後に取得した時点のものです。
4. 当方は、本サービスの利用により利用者に生じた損害について、当方に
   軽過失があるにとどまる場合、利用者が直近【　　】か月間に当方へ
   支払った利用料金の額を上限として、賠償の責任を負います。
5. 前項は、当方に故意または重大な過失がある場合には適用しません。
6. 決済代行会社の障害その他、当方の責めに帰することができない事由に
   より決済を行うことができなかった場合について、当方は責任を負い
   ません。

**第15条（本サービスの変更、中断および終了）**

1. 当方は、利用者への事前の通知により、本サービスの内容を変更し、
   またはその提供を終了することがあります。
2. 次の各号のいずれかに該当する場合、当方は、事前の通知なく本サービスの
   提供を中断することがあります。
   - 設備の保守または障害が生じた場合
   - 天災その他の不可抗力により提供が困難となった場合
3. 当方は、本サービスの提供を終了する場合、利用者が支払を了した期間の
   うち未経過の部分について、【　返金する／利用期間の満了まで提供を
   継続する　】ものとします。

**第16条（利用の停止および登録の抹消）**

当方は、利用者が本規約に違反した場合、事前の通知なく、本サービスの
利用を停止し、または登録を抹消することがあります。この場合において、
支払を了した利用料金の返金は行いません。

**第17条（退会）**

1. 利用者は、本サービス上の所定の方法により、いつでも退会することが
   できます。
2. 退会により、自動更新は停止します。
3. 退会により、アカウント、表示名および顔写真は削除されます。
4. お気に入りおよび閲覧履歴は利用者の端末内にも保存されており、これらは
   端末の操作により削除することができます。
5. 退会した場合においても、残存期間に相当する金額の返金は行いません。

**第18条（本規約の変更）**

当方は、必要と判断した場合、本規約を変更することがあります。変更後の
規約は、本サービス上に掲示した時点から効力を生じます。

**第19条（準拠法および管轄）**

1. 本規約は、日本法に準拠し、日本法に従って解釈されるものとします。
2. 本サービスに関して紛争が生じた場合、【　　　地方裁判所　】を
   第一審の専属的合意管轄裁判所とします。

4. 管理画面における操作は記録し、何時、誰が、何を変更したかを確認

**6. 開示、訂正および削除**

2. 表示名および顔写真は、本サービス上で本人が変更し、または削除する

## 9. 閲覧履歴 — 依頼 / 1.0人日

「最近見たスポットが履歴として出ない」「すべて見るが押せない」とのご指摘により実装。

**なぜ範囲外か:** `docs/04-scope-and-acceptance.md` では閲覧履歴を第2フェーズ
（運用版）に置いていた。ご依頼により初期版へ前倒しした。

内訳:

| 作業 | 人日 |
|---|---|
| 履歴の保存と読み出し | 0.3 |
| 履歴の画面（1件削除・すべて削除） | 0.4 |
| 探す画面との接続、「すべて見る」の動作 | 0.3 |

**何を残しているか:** 施設の id と開いた時刻だけ。名前も住所も控えない。
控えると、施設側が変わったときに古い内容が履歴に残り続ける。
表示のたびに端末のデータベースから引き直している。

**どこに残しているか:** 端末の中だけ。サーバーへは送らない。
どのドライバーがどの施設を見たかは、送る必要のない情報にあたる。

**消せるようにした理由:** 行き先の履歴は、端末を貸したり覗かれたりしたときに
その人の仕事の中身がそのまま出る。1件ずつと、まとめての両方を用意した。

関連: `app/src/lib/history.ts`, `app/src/app/(tabs)/history.tsx`

## 12. PWA 化（配信基盤を含む） — 依頼 / 4.0人日

「ストアの利用料が不要になる」「より多くの人が使える」という理由で、
クライアント様が PWA での提供をご希望された（2026-09-03 のやり取り）。

**なぜ範囲外か:** 合意書は App Store / Google Play での配布を前提と
しており、web での提供は含まれていない。

内訳:

| 作業 | 人日 |
|---|---|
| Expo SDK 54 → 57 への更新（RN 0.81 → 0.86） | 1.0 |
| PWA の基盤（manifest・Service Worker・アイコン・オフライン設計） | 1.0 |
| 保存先を SQLite から IndexedDB へ移行 | 1.5 |
| 配信環境（Vercel）の構築と検証 | 0.5 |

**SDK 更新が必要だった理由:** クライアント様の Expo Go が SDK 57 のみ
対応で、SDK 54 のままでは実機確認ができなかった。

**保存先の移行が必要だった理由:** expo-sqlite の web 版は OPFS を
必要とし、**Safari では動かない**。iPhone で使えないなら、PWA にする
理由（より多くの人が使える）が成り立たない。

**ネイティブ向けの作業が無駄になった点:** react-native-maps の導入と
APK のビルドは PWA では使わない。方針決定前に着手していたため。

関連: `app/public/`, `app/src/lib/catalog.ts`, `app/vercel.json`

## 13. 施設数 150件 → 193件 — 依頼 / 1.0人日

`docs/04-scope-and-acceptance.md` の受入条件は「**150件を登録できる状態**」。
2026-09-03 にいただいた一覧は **193件**で、43件多い。

**投入そのものは自動化してあるため、件数に比例した手間はかからない。**
加算しているのは、件数が増えたことで新たに必要になった次の作業。

| 作業 | 人日 |
|---|---|
| 一覧（.xlsx）の読み取り（よみがな・結合セル・全角括弧の扱い） | 0.5 |
| 市区町村の対応表を国土地理院のものへ差し替え | 0.25 |
| 施設コードの振り直しと写真の保存先の移動 | 0.25 |

**表の読み取りに手間がかかった理由:** よみがなが `<rPh>` として
セルの中に埋め込まれており、単純に読むと共有文字列の番号がずれて
別のセルの値になる。エリア見出しの空セルも数値として読めてしまい、
施設番号を誤る。専用の読み取りを書いた（`tools/lib/xlsx.mjs`）。

**対応表の差し替えが必要だった理由:** 従来は都心9区分を手で書いていた。
193件には千葉県（浦安・船橋）と大田区が含まれ、知らないコードが来ると
住所が空欄になる。国土地理院の表（1,919件）をそのまま取り込んだ。

**コードの振り直し:** お手元の一覧と画面を番号で対応させるご要望により、
施設コードを一覧の番号に合わせた（69番 → `HTL-0069`）。
写真の保存先もコードを含むため、あわせて移した。

関連: `tools/import-sheet.mjs`, `tools/build-catalog-from-sheet.mjs`,
`tools/lib/xlsx.mjs`, `tools/lib/muni.mjs`, `docs/09-data-issues.md`

## 14. PC 向けの画面（左右分割を含む） — 依頼 / 4.0人日

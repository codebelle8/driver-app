## クライアント様にご確認いただきたいこと

### 1. よみがな — 193件中 150件が未記入

一覧の「よみがな」欄が入っているのは **43件**のみ。

未記入の150件は、検索用のよみがなとして施設名をそのまま入れてある。
そのため次のようになる。

| 打った文字 | 帝国ホテル東京（よみがな未記入） |
| --- | --- |
| 帝国 | **出る** |
| ホテル | **出る** |
| ていこく | 出ない |

**漢字・カタカナでは引けるが、ひらがなでは引けない**状態。
当方で推測して埋めることもできるが、読み違いが混ざる恐れがある
（「星のや」「一休」のような、読みが一意でない名前が含まれるため）。

いただければ確実に埋まる。ご判断を伺いたい。

なお区分名でも引けるようにしてあり、**「ホ」の1文字で193件すべてが出る**。
施設名に「ホテル」を含まない「星のや東京」なども、これで辿れる。

## 取り込みの方針

### 施設名はいただいた表記のまま

当方で正式名称へ直さない。一覧と画面が1対1で対応していないと、
クライアント様が確認される際に照合できなくなるため。

正式名称や略称は**別名**に入れてあり、検索はどちらでも届く。

### 進入路の注記もいただいた文面のまま

当方で言い換えると、原文にない意味が混ざる。

たとえば「地下駐車場B2Fから27F」を「27階へお上がりください」と書き換えると、
27階が受付なのか通路なのかを当方が決めてしまうことになる。
B2F / 1F の表記は乗務員の方には通じるため、そのまま出す。

注記が無い152件には、次の文言を入れてある。

> 現地調査前です。座標のみ登録されています。到着後の進入方法は追ってお知らせします。

### 住所は座標から引いている

いただいた一覧に住所は無い。国土地理院の逆ジオコーディングを使い、
座標から**町丁目まで**を割り出している。

鍵もアカウントも不要で、国が整備した住所データが返るため、
Google Maps の API キーを待たずに進められた。

市区町村の対応表も国土地理院のものをそのまま取り込んでいる
（`tools/lib/muni.mjs`、1,919件）。以前は都心9区分を手で書いていたが、
193件には千葉県（浦安・船橋）や大田区が含まれ、足りなくなった。

### 「車寄せ」有無の扱い

一覧の「有」「無」を、進入口の種別に対応させている。

| 一覧 | 進入口の種別 | 画面の表示 |
| --- | --- | --- |
| 有 | dropoff | 車寄せ |
| 無 | entrance | エントランス |

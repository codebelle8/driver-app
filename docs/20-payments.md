## 作り方の決まり

* **使えるかどうかを決めるのは、いまと同じ `paid_until` 1つ。** 画面の絞り込み（`plan-gate`）、圏外の控え、
  上位の方の無料、試験提供が、すべてここを通っている。別の決め手を足すと、電波の無い場所でだけ締め出される、が起きる
* **`paid_until` を書くのはサーバーだけ。** Stripe からの知らせ（署名を確かめる）を受けて書く。アプリから「払った」とは書かせない
* **同じ知らせが2回届いても、二重に延ばさない**（知らせの番号を控え、済んだものは飛ばす）
* **カード番号はこちらを通さない。** 入力は Stripe の画面で行う（割賦販売法の「持たない」。本人確認の 3Dセキュアも Stripe が行う）
* 銀行振込の「入金を確認した」は残し、並べて使う

### 規約と組み合わせるところ

* 無料期間の途中で申し込んだ方は、残りの日数のあとから有料の期間を始める（第5条2項）
* 上位20名に入った有料の方は、1か月延ばす。自動更新の方は、次の引き落としを1か月後ろへずらす
* 12か月払いの途中解約は、第11条の計算（残りの月数 − 2）× 500円 で返金する。管理画面で金額を出す
* 有料を始める時点で無料期間を過ぎている方は、そこから1か月無料（第4条7項）

## 気をつけること

* **PayPay（Stripe）は都度払いだけ。** Stripe の資料で継続課金は対応外。自動更新の支払い画面には出せない。
  1か月分・12か月分をその都度買っていただき、期限が来たらあらためて手続きいただく（第7条10項）
* PayPay は Stripe の管理画面で別に有効にする必要がある（審査があるか、個人事業主で使えるかは、お申し込みの際に確かめる）
* **領収書（適格請求書）** には、登録番号と、税率ごとの消費税額（10%）が要る。Stripe の料金は「税込 10%」で作る
* **銀行振込の方の領収書は Stripe から出ない。** こちらの仕組みから出す必要がある（4 か 7 で扱う）
* 将来アプリストアに出す場合は、そのときにストアの課金の決まりを確かめ直す

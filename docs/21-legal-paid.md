1. 利用者は、メールアドレスおよびパスワードを自己の責任において

2. 1つのアカウントで同時に利用できる端末は1台とします。別の端末で

3. 利用者は、アカウントを第三者に譲渡し、貸与し、または共有しては

4. アカウントを用いて行われた行為は、利用者本人の行為とみなします。
5. 通信ができない場所においては、当方は、利用者の端末に保存された

   回復した後に改めて確認します。利用の停止、他の端末でのログインその
   他の変更は、当該確認の時点から反映されます。
6. 当方が前項の確認を最後に行った時点から当方が定める日数を経過した
   場合、利用者は、通信ができる場所で改めて確認が行われるまでの間、
   本サービスを利用することができません。
7. 通信ができない場所においては、ログアウトを行うことができません。

1. 本サービスは、現在、試験提供の期間にあります。
2. 試験提供の期間中、当方は利用料金を請求しません。
3. 試験提供の期間中、当方は、本サービスの内容、画面および機能を、

4. 当方は、試験提供の期間を終了し有料での提供を開始する場合、開始の

   メールアドレスへの送信により、その旨を通知します。
5. 前項の通知により、利用者が自動的に有料の利用に移行することは
   ありません。有料の利用は、利用者が第7条に定める手続きを行った
   時点から開始します。
6. 試験提供の期間中は、第5条に定める無料期間が経過した後も、利用者は

7. 試験提供の期間を終了し有料での提供を開始する時点で、第5条第1項に
   定める無料期間を経過している利用者は、有料での提供を開始した日から

**第5条（無料期間）**

1. 利用者は、登録日から1か月間、無料で本サービスを利用することが

2. 無料期間中に有料の利用を開始した場合、無料期間の残存期間は消滅せず、
   当該残存日数に利用者が選択した期間を加えた期間を、利用期間と

3. 無料期間の経過後、有料の利用を開始しない場合、利用者は本サービスの
   機能の一部を利用することができなくなります。
4. 第4条第7項により無料で利用することができる期間は、第2項および
   第8条第2項の適用については、無料期間とみなします。

6. 自動更新の対象とならない支払方法を選択した場合、利用者は、期間の

   とします。

**第8条（継続課金および自動更新）**

1. 前条第4項により自動更新の対象となる支払方法を選択した場合、利用者が

2. 前項の支払方法により無料期間中に申し込んだ場合、最初の決済は、
   無料期間が満了する日に行います。無料期間の経過後に申し込んだ場合、
   最初の決済は、申込みの時点で行います。

   より前後することがあります。
4. 当方は、更新に先立ち、更新日および金額を、本サービス上の通知または

6. 利用者は、支払方法に関する情報に変更が生じた場合、速やかに本サービス
   上で登録内容を更新するものとします。

**第11条（返金）**

4. 第2項の500円は、12か月分の利用料金5,000円を10か月で除した額であり、
   同項の2か月は、一括払いによる割引（2か月分）に相当するものです。

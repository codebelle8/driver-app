### A-3. 緯度経度の取得方法

正確な車寄せ位置の座標が最も重要です。取得手順は以下の2通りで、どちらでも構いません。

1. **クライアント側でご入力**
   PC版 Google マップで該当地点を右クリック →
   一番上に表示される数値（例: `35.6656, 139.7604`）をクリックするとコピーされます。
   これをそのままスプレッドシートに貼り付けてください。
2. **当方で仮設定 → ご確認**
   住所と進入方法の説明文から当方が座標を仮置きし、管理画面の地図上でご確認・修正いただく。

※ 建物の中心ではなく、**実際に車を停める位置**の座標が必要です。
※ 管理画面には地図上でピンをドラッグして修正する機能を用意しますので、
   後からの微調整は簡単に行えます。

## B-2. ストアアカウントと権利関係

**ストアアカウントはクライアント様名義で取得いただき、当方を開発者として招待いただく形を強く推奨します。**
アプリの所有権が確実にクライアント様に残り、当方に万一何かあっても資産が失われません。

| 項目 | 内容 | 注意点 |
|---|---|---|
| Apple Developer Program | 法人 / 個人 | 法人の場合 **D-U-N-S番号** が必要。取得に1〜2週間かかるため早めの着手を推奨（年額 約15,000円） |
| Google Play Console | 法人 / 個人 | **個人名義の新規アカウントは、本番公開前に「20名で14日間のテスト」が必須**です。法人名義は対象外のため、法人での取得を推奨（初回 約4,000円） |
| Google Cloud（地図API） | 請求先アカウント名義 | クレジットカード登録が必要。名義をご指定ください |
| 運営者情報 | 会社名 / 所在地 / 問い合わせ先メールアドレス | ストア掲載とプライバシーポリシーに必須 |
| プライバシーポリシー・利用規約 | 掲載先URL | 既存サイト内に設置可能か、当方で用意する必要があるか |

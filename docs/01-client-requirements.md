# 初期版 (MVP) 完成に必要な確認事項 — クライアント提出用

作成日: 2026-08-06 / 更新: 2026-08-06（優先順位を再編）
対象: 初期リリース版のみ（運用版・最終版は別途）

## 方針

**ストアアカウント（Apple / Google Play）の依頼は、完成版をご確認いただいた後に行う。**
着手金のご入金前という段階を踏まえ、クライアント様に金銭的な準備を求める前に、
まず動くものをお見せすることを優先する。

**施設データが未整備でも開発は止めない。** 仮の写真・案内図（プレースホルダー）で
全画面を実装し、実データは管理画面から後で差し替える。画面の作り直しは発生しない。

| 記号 | 意味 | 期限目安 |
|---|---|---|
| **A** | これが無いと設計を確定できない（＝本当に今必要なもの） | 今週中 |
| **B** | 実装と並行して順次で可（プレースホルダー運用が可能） | 随時 |
| **C** | 完成版のご確認後に着手 | リリース準備フェーズ |

## B. 実装と並行して順次いただくもの

### B-1. 施設データ 150件 — **ご準備状況の確認が先**

まず「現時点でどこまで揃っているか」を伺う。以下のいずれでも開発は進行できる。

| 状況 | 進め方 |
|---|---|
| 揃っている | スプレッドシート雛形に転記いただき、順次投入 |
| 一部のみ揃っている | 揃っている分を先に投入し、残りはプレースホルダーで実装 |
| これから収集する | **全件プレースホルダーで実装**。完成後、管理画面から順次差し替え |

**プレースホルダー運用の内容**
- 写真・案内図は「準備中」を示すダミー画像を表示（デザインは実データと同じ枠で表示）
- 施設名・住所・説明文はサンプル値を投入し、レイアウト崩れの検証に使う
- 実データへの差し替えは**管理画面からの入れ替えのみ**で完了し、アプリの改修は不要

**サンプル10件のお願い**
可能であれば、写真・案内図・座標まで完全に揃った **10施設分** を先にいただきたい。
この10件で形式を確定し、残り140件の雛形とすることで後戻りをほぼ無くせる。

### B-2. 緯度経度の取得方法

1. **クライアント側でご入力** — PC版 Google マップで該当地点を右クリック →
   一番上の数値（例: `35.6656, 139.7604`）をクリックでコピー → 貼り付け
2. **当方で仮設定 → ご確認** — 住所と進入方法から仮置きし、管理画面の地図上で修正

※ 建物の中心ではなく、**実際に車を停める位置**の座標。
※ 管理画面に地図上でピンをドラッグして修正する機能を用意するため、微調整は容易。

| 解像度 | 長辺1600px以上を推奨（アプリ側で自動圧縮） |
| 命名規則 | `施設ID_区分_連番.jpg`。当方でテンプレート送付 |
| キャプション | 「正面車寄せ（夜間）」等の短い説明 |
| 権利 | 自社撮影か、第三者提供素材か |

## C. 完成版のご確認後に着手（今は依頼しない）

> **この節の内容は、動作するアプリをご確認いただいた後にご案内する。**
> 現段階でクライアント様に費用負担や事務手続きを求めない。

### C-1. ストアアカウント

**アカウントはクライアント様名義で取得いただき、当方を開発者として招待いただく形を推奨。**
アプリの所有権が確実にクライアント様に残る。

| 項目 | 内容 | リードタイム |
|---|---|---|
| Apple Developer Program | 法人の場合 **D-U-N-S番号**が必要 | **1〜2週間**（年額 約15,000円） |
| Google Play Console | **個人名義の新規アカウントは本番公開前に「20名で14日間のテスト」が必須**。法人名義は対象外 | 法人推奨（初回 約4,000円） |
| Google Cloud（地図API） | 請求先アカウント名義 | 即日 |

> **内部メモ（クライアントには送らない）**
> 上記により、「完成版のご確認」から「ストア公開」までに **2〜4週間**の
> リードタイムが発生する。完成版デモの時点でこの見通しを併せて提示し、
> 公開日が後ろ倒しになる印象を与えないようにする。
> なお開発中の実機テスト配布は EAS の internal distribution で行えるため、
> Apple / Google のアカウントが無くても検証は可能。

### C-2. 公開に必要な情報

- 運営者名 / 所在地 / 問い合わせ先メールアドレス
- プライバシーポリシー・利用規約の掲載先URL

### C-3. 実機テスト

| 確認項目 | 内容 |
|---|---|
| テスト参加者 | 実際に運転されるドライバー 3〜5名 |
| 端末 | iPhone / Android の内訳、機種名、OSバージョン |
| テスト期間 | 1〜2週間 |

**車で現地へ向かい「ナビの到着地点が実際の車寄せと合っているか」を確認する工程が
最重要の検収項目。** 省くと公開後に「案内された場所が違う」という不具合が残る。

### C-4. 今後のフェーズに影響する確認

初期版では実装しないが、拡張しやすい構造にするため方針のみ伺う。

| 項目 | 確認したいこと |
|---|---|
| 無料期間 | 起算日と、有料化時期の目安 |
| 課金 | 想定価格帯、支払者（ドライバー個人 / タクシー事業者） |
| ログイン方式 | メールアドレス / 電話番号 / 会社コード |

※ 支払者が「タクシー事業者」の場合、Apple の手数料（15〜30%）を回避できる
　 法人向け配布方式が使える可能性がある。課金機能の設計前に確認が必要。

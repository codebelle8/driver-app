# 現地写真 撮影ガイド — クライアント提出用

作成日: 2026-08-07

このガイドは、**撮り直しを減らすこと**を目的としています。
先に読んでいただければ、1施設あたり10分程度で必要な写真が揃います。

---

## いちばん大切なこと

### 運転席の目線の高さで撮る

**これだけは守っていただきたい点です。**

立った姿勢（目線 150〜160cm）で撮った写真は、運転席（目線 120〜130cm）から見た
景色とかなり違って見えます。歩行者目線だと看板や植栽の上が見えてしまい、
実際に運転席から見える景色と一致しないため、現場で役に立ちません。

- **しゃがむ、または車内から撮る**のが確実です
- 車を停めて、**運転席に座ったまま**撮っていただくのが最も正確です
- フロントガラス越しでも構いません（反射が強い場合は窓を開けて）

### 横向き（横長）で撮る

アプリの写真表示枠は横長です。縦向きで撮ると上下が大きく切れます。
**スマートフォンを横に倒して**撮影してください。

### 進行方向を向いて撮る

「これから進む方向」を写してください。振り返って撮った写真は、
ドライバーが実際に見る景色と逆になるため使えません。

## 1進入口あたり、この4枚

| # | 何を撮るか | どこから撮るか | ドライバーが判断すること |
|---|---|---|---|
| 1 | **進入路** | 曲がる地点の**手前50〜100m**、道路上から進行方向へ | 「そろそろだ」と身構える。車線変更の判断 |
| 2 | **進入口** | 曲がる地点そのもの。目印が写るように | 「ここを曲がる」の確定。行き過ぎの防止 |
| 3 | **車寄せ** | 実際に停車する位置 | どこに着けるか。何台停まれるか |
| 4 | **エントランス** | 降車したお客様が向かう入口 | 「お降りはこちらです」と案内できる |

**1番と2番が最も価値があります。** 3番・4番は地図や既存の写真でも代替できますが、
「どこで曲がるか」は現地写真でしか分かりません。

### 時間が取れない場合の優先順位

1. **進入口（#2）** — これ1枚だけでも十分価値があります
2. 進入路（#1）
3. 車寄せ（#3）
4. エントランス（#4）

**1枚もないよりは1枚ある方が圧倒的に良い**ので、迷ったら #2 だけでもお願いします。

## 撮影のコツ

### 目印を必ず入れる

ドライバーが照合するのは建物ではなく**目印**です。以下が写り込むようにしてください。

- 信号機、横断歩道
- 看板、店舗名、コンビニ
- 特徴的な建物、街路樹
- 「◯◯ホテル 入口」などの案内表示

建物だけをきれいに撮った写真より、**電柱や看板が写った雑然とした写真の方が
現場では役に立ちます。**

### 水平を保つ

スマートフォンのグリッド表示をオンにすると撮りやすくなります。
（iPhone: 設定 → カメラ → グリッド／Android: カメラアプリの設定 → グリッド）

### 逆光を避ける

太陽を背にして撮ってください。逆光だと看板の文字が読めなくなります。
**午前中は東向き、午後は西向きの撮影が難しくなる**ため、
ルートを組むときに考慮していただけると効率的です。

### 画質の設定

スマートフォンの標準設定で問題ありません。特別な設定は不要です。
（アプリ側で自動的に圧縮しますので、高画質のまま送っていただいて構いません）

## 夜間写真について

**ホテルとレジデンスは、夜間のご利用が多い施設です。**
照明が点くと昼とは見え方が大きく変わり、昼の写真だけでは夜に役立ちません。

- 主要施設だけでも、**夜間の車寄せを1枚**撮っていただけると価値が高いです
- 特に、車寄せの照明が暗い施設、入口が分かりにくい施設を優先してください
- 全施設で撮る必要はありません。**「夜は分かりにくい」と感じた施設**だけで十分です

---

## 注意していただきたいこと

### 安全について

- **運転中の撮影は絶対に行わないでください。** 必ず停車してから撮影してください
- 路上駐車が難しい場所では、無理をせず後日改めてください
- 歩道からの撮影時は通行の妨げにならないようご注意ください

### 撮影許可について

- **レジデンス（マンション）は特にご注意ください。** 敷地内での撮影は、
  管理室・コンシェルジュに一声かけてからの方が確実です
- ホテルの車寄せも、長時間の撮影は事前に一言お伝えいただくと安心です
- 公道からの撮影は基本的に問題ありません

### 写り込みについて

- **人物の顔**が大きく写らないようご配慮ください
- **車のナンバープレート**もできるだけ避けてください
- 写り込んでしまった場合は、別のカットを撮っていただくか、
  そのままお送りいただければ**当方で加工処理いたします**

## ファイル名について

**撮影時点では、ファイル名を気にしていただく必要はありません。**

施設ごとにフォルダを分けていただければ、当方でリネームいたします。

```
📁 グランドホテル汐留
   ├─ 正面車寄せ
   │    ├─ IMG_1234.jpg   （進入路）
   │    ├─ IMG_1235.jpg   （進入口）
   │    └─ IMG_1236.jpg   （車寄せ）
   └─ 宴会場エントランス
        └─ IMG_1240.jpg
```

このように**施設名／進入口名のフォルダに入れていただくだけ**で結構です。
どれがどの写真かは、撮影順から判断できますので問題ありません。

余裕があれば、フォルダ内にメモ（`メモ.txt`）で
「1枚目=進入路、2枚目=進入口」と書いていただけると確実です。

## 1施設あたりの撮影手順（目安10分）

1. 施設の**手前100mほどで停車**し、進行方向を撮る（#1 進入路）
2. **曲がる地点まで進んで停車**し、目印が入るように撮る（#2 進入口）
3. **車寄せに進入して停車**し、停車位置を撮る（#3 車寄せ）
4. **降車せず車内から**、お客様が向かう入口を撮る（#4 エントランス）
5. 進入口が複数ある施設は、2〜4を繰り返す
6. 気づいたこと（高さ制限、時間帯の制約、警備員の有無など）をメモ

**手順6のメモが、実は写真と同じくらい重要です。**
「17時以降は送迎バスで塞がる」「天井が低くワゴンは不可」といった情報は
写真からは読み取れないため、お気づきの点は何でもお知らせください。

## 案内図について

進入案内図は、**写真とメモが揃っていれば後からでも作成できます。**
撮影を優先していただき、案内図は後回しで問題ありません。

案内図の作成をご希望の場合は、別途ご相談ください。

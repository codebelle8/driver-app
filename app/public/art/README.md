# 画面に敷く写真の置き場

PC で開いたときの「探す」画面に敷く写真を、ここへ置きます。

**この名前で置いてください。** 拡張子は `.png` でも `.jpg` でも構いません。

| 名前 | 使われる場所 | 目安の大きさ |
| --- | --- | --- |
| `hero-1` | 上部。1枚目 | 横 1600 × 縦 760 前後（横長） |
| `hero-2` | 上部。2枚目 | 同上 |
| `hero-3` | 上部。3枚目 | 同上 |
| `hero-4` | 上部。4枚目 | 同上 |
| `hero-5` | 上部。5枚目 | 同上 |
| `rail` | 左メニューの下半分 | 横 520 × 縦 760 前後（縦長） |

上部の5枚は **5秒ごとに重なりながら入れ替わります。**

**5枚すべてが揃っていなくても動きます。** 置かれている枚数だけで回り、
1枚だけなら止まったまま、1枚も無ければ淡い緑の面になります。

## 置いたあと

**軽くしてから配ります。**

    node tools/build-art.mjs

これで表示に要る大きさの `.jpg` が作られ、原本は `assets/art/` へ移ります。
いただいた原本は1枚で 2.5MB あり、5枚だと12MBを超えます。
そのまま配ると最初の表示が目に見えて遅くなります。

何度実行しても構いません。整え済みのものは触りません。

**この作業をしなくても写真は出ます。** `.png` のままでも読み込まれます。
軽くしたほうが速い、というだけです。

## 作りのご注意

**hero-1〜4 — 主題は右寄せに**
左半分には「行きたい場所を見つけよう」と検索欄が乗ります。
左端は背景色へ溶かして消えるため、車や人物は右寄りに写っているものが収まります。

高さは 280px で切り取ります。**右上を基準に切る**ため、下側（足元や路面）が
切れます。人物の頭が入るように撮られたものをお選びください。

**5枚は同じ切り取り方で並びます。** 寄りと引きが混ざると、入れ替わるたびに
主題の大きさが跳ねて落ち着きません。近い構図で揃えたほうが収まります。

**rail — 主題は下寄せに**
上端は行先の並びに向かって消えていきます。下半分に主題が写っているものが収まります。
下端には「スムーズな到着を、もっと快適に。」の文字が重なりますが、
その範囲は下地の色へ戻すため、写真の明るさは問いません。

**どちらも**
- 1枚あたり 500KB 以内を目安に（`tools/build-art.mjs` を通せば自動で収まります）
- 人物の顔が写るものは、肖像の許諾をご確認ください

## 動きについて

- 別のタブへ移っているあいだは止まります（見られていない絵で電池を使わないため）
- 端末側で「視差効果を減らす」を選んでいる方には、1枚目のまま止めて出します
